## What is it?

**IEB Project Assistant** brings learning and building into one desktop app. Describe your idea — the AI helps you plan, teaches best practices, fixes your codebase, or ships features with you in control.

Use your own API keys (OpenRouter, Groq, OpenAI, DeepSeek, Gemini, Anthropic, and more). Your projects stay on your machine.

## Who is it for?

- **Beginners** — stack choices, folder structure, and step-by-step guidance  
- **Students & hobbyists** — homework, games, web apps, Python projects  
- **Experienced devs** — scan projects, surface issues, edit in-app  
- **Fast builders** — Vibe Coding with approve/reject before any file changes

## Three AI modes

### Setup Guide — Learn
Tell the AI your project idea. Get a roadmap, technology recommendations, and explanations you can actually follow.

### Project Fixer — Fix
Open a folder and scan. See errors and improvements; each item explains how to fix it, with the right line highlighted in the editor.

### Vibe Coding — Build
Describe what to build. The AI plans files, todos, and code — nothing is written until you **Approve**. A comfort-zone warning keeps learning mode intentional.

## Quick start

1. **[Download the installer](https://github.com/iebgames/ieb-project-helper/releases/download/v1.0.0/IEB-Project-Assistant-Setup-1.0.0.exe)** (Windows v1.0.0)  
2. Add API keys to `.env` next to the app (or via Settings)  
3. Open a project folder from the sidebar, or start with **Setup Guide**  
4. Pick a mode: learn, fix, or vibe-build
